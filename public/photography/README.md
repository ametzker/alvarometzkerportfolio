# Photography

Put your JPG, PNG, WebP or AVIF images in this folder.
Add each image to `photography` in `src/data.js`, in display order:

```js
export const photography = [
  {
    src: "/photography/example.jpg",
    alt: "A description of the photograph",
    caption: "Optional title / location / year",
  },
];
```

Use the exact filename, including capitalization. Rebuild and publish to show new images.
The section shows “Coming soon” until photographs are added.
